# 电力现货市场出清仿真平台（MarketClearingPro）

东南大学《C++ 程序设计》课程设计作品 —— 一款轻量、可交互、结果可校核的电力现货市场出清仿真工具。
模拟日前市场 96 时段双侧申报、统一边际价格出清（Pay-as-Clear）、直流潮流安全校核与节点边际电价（LMP）计算、结算与阻塞盈余校验的全流程闭环。

## 功能特性

- **双侧报价申报**：发/用电双侧 96 时段（15 分钟颗粒度）报价编辑，支持阶梯报价与二次曲线报价 `P = aQ² + bQ + c`
- **统一边际价格出清**：供给升序、需求降序，双指针撮合求系统边际价格 SMP 与出清电量（曲线报价按微段离散后同池撮合）
- **安全校核与节点电价**：直流潮流 + PTDF 灵敏度矩阵校核线路越限，阻塞时再调度（redispatch），输出各节点 LMP = 能量分量 λ + 阻塞分量
- **结算与自校验**：发电收入、用电支出、阻塞盈余逐时段列示，内建恒等式「用电支出 − 发电收入 = 阻塞盈余」自动核算（容差 1e-6）
- **可视化**：市场总览看板、供需曲线交点、节点电价分化、申报明细、结算结果共 7 个交互页面（ECharts）
- **桌面端分发**：Electron 打包为 NSIS 安装向导与绿色便携版，离线可用

## 技术架构

三层解耦，算法与界面分离，引擎为无副作用纯函数：

```
界面层  index.html + js/app.js   Vue 3 + ECharts，7 个交互页面
  ↓ 调用 / 渲染
数据层  js/store.js              三节点电网场景播种、localStorage 持久化、导入导出
  ↓ 驱动计算
引擎层  js/engine.js (610 行)    双指针撮合 · PTDF 直流潮流 · LMP 分解 · 结算校核
```

技术栈：Vue 3 · ECharts · Electron · Git（全部依赖已 vendor 化，离线可运行）

## 快速开始

### 方式一：浏览器直接运行（无需安装）

双击 `index.html`，或用任意静态服务器打开：

```bash
python -m http.server 8000
# 访问 http://127.0.0.1:8000
```

### 方式二：桌面端

直接使用已打包产物（见 `pack/dist/` 或随附安装包）：

- `电力现货市场出清仿真平台-setup-1.0.0.exe` —— NSIS 安装向导
- `电力现货市场出清仿真平台-便携版-1.0.0.exe` —— 绿色便携版，双击即用

### 运行测试

```bash
node tests/engine.test.js     # 引擎测试：30 项断言（无约束出清 / PTDF / 阻塞 LMP / 对照组 / 曲线报价 / 报价校验）
node tests/mount.test.js      # 界面挂载测试（需先 npm i jsdom）
```

### 重新打包桌面端

```bash
cd pack
npm install
npx electron-builder --win        # 输出到 pack/dist/
```

## 核心算法

### 1. 统一边际价格出清（双指针撮合，O(n log n)）

卖方报价升序、买方报价降序；双指针推进，`P卖[i] ≤ P买[j]` 即成交 `min(qᵢ, qⱼ)`，否则停止。
SMP = 边际成交段价格，全体中标者按此价结算。二次曲线报价按 ΔQ 切分为微段（段价取区间中点函数值）后与阶梯报价同池撮合。

### 2. PTDF 直流潮流与 LMP

```
fₗ = Σₙ PTDF[l,n] · Pₙ        校核 |fₗ| ≤ Fₗ^max
LMPₙ = λ − Σₗ μₗ · PTDF[l,n]   λ：能量分量；μₗ：线路 l 阻塞影子价格
```

阻塞时按越限方向「增贵减廉」再调度，直至潮流回落至限值内；结算满足
`Σ Load·LMP − Σ Gen·LMP = Σₗ μₗ · Fₗ`（阻塞盈余），平台每时段自动核算。

### 引擎 API（js/engine.js）

| 函数 | 说明 |
| --- | --- |
| `runPeriod(participants, net, opts)` | 单时段出清：返回 SMP、中标明细、潮流、LMP、阻塞盈余等 |
| `computePTDF(nodes, lines, slackId)` | 计算 PTDF 灵敏度矩阵（指定平衡节点） |
| `validateBid(p)` | 报价合法性校验（单调性 / 非正电力 / 曲线参数缺失等） |

## 测试验证

`tests/engine.test.js` 实跑结果 **30 通过 / 0 失败**，6 个用例组：

1. 无约束出清 —— 与手工核算对照（470 MW / 260 元·MWh⁻¹，收支相等误差 < 0.01 元）
2. 三节点网络 PTDF —— 与解析解 (0, −0.75, −0.5) 逐项比对（容差 1e-9）
3. 阻塞再调度 —— LMP 分解（100 / 200 / 166.7 元）、影子价格 μ=133.3、盈余 20000 元
4. 对照组 —— 放宽线路容量后回归统一电价、盈余归零
5. 二次曲线报价 —— 出清价 ≈ C(300) = 255 元
6. 报价合法性校验 —— 非法报价全部拦截
